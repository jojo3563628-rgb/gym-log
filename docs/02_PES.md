本文件描述「使用者看得到的行為」：畫面、欄位、操作流程、規則。不涉及程式怎麼寫（那是 SW Arch / PIS 的事）。

## 1. 名詞定義

| 名詞 | 定義 |
|---|---|
| 動作項目 | 動作庫裡的一筆，可以是機台、自由重量或徒手動作 |
| 訓練群組 | 自建的一組訓練內容，例如「推日」，包含部位與動作清單 |
| 排程 | 把某個訓練群組指定到某一天 |
| 訓練（Session） | 實際做的一次訓練，有日期，內含多個動作的多組紀錄 |
| 組（Set） | 一組的紀錄：重量、單位、次數、備註 |
| 訓練量 | 見第 6.2 節 |

## 2. 畫面架構

底部固定 5 個分頁：

```
[ 今天 ]  [ 行事曆 ]  [ 動作庫 ]  [ 歷史 ]  [ 設定 ]
```

| 畫面編號 | 名稱 | 進入方式 |
|---|---|---|
| SCR-01 | 今天（首頁） | 分頁「今天」，App 開啟預設畫面 |
| SCR-02 | 記錄畫面 | SCR-01 點某個動作 |
| SCR-03 | 休息計時器 | SCR-02 完成一組後自動出現 |
| SCR-04 | 行事曆 | 分頁「行事曆」 |
| SCR-05 | 訓練群組清單／編輯 | SCR-04 右上「群組」 |
| SCR-06 | 動作庫清單 | 分頁「動作庫」 |
| SCR-07 | 動作項目頁（說明＋影片） | SCR-06 點項目，或 SCR-02 點 ⓘ |
| SCR-08 | 動作項目編輯 | SCR-07 點「編輯」，或 SCR-06 點「＋」 |
| SCR-09 | 歷史紀錄 | 分頁「歷史」 |
| SCR-10 | 單一動作趨勢圖 | SCR-09 或 SCR-07 點「趨勢」 |
| SCR-11 | 設定（單位、匯出、匯入） | 分頁「設定」 |

## 3. 畫面規格

### SCR-01 今天

```
┌──────────────────────────────┐
│ 2026-10-07（三）              │
│ 今日排程：推日                 │
├──────────────────────────────┤
│ ○ 坐姿推胸機      上次 40kg×10 │
│ ● 肩推機   已完成 3 組          │
│ ○ 三頭下壓        上次 25kg×12 │
│ [ ＋ 加入其他動作 ]             │
├──────────────────────────────┤
│ [ 結束今天的訓練 ]              │
└──────────────────────────────┘
```

| 項目 | 規則 |
|---|---|
| 有排程 | 列出該群組的動作清單（依群組設定的順序） |
| 無排程 | 顯示「今天沒有排程」，提供「選擇群組開始」與「自由訓練」兩個按鈕 |
| 動作狀態 | ○ 未做、● 已記錄至少 1 組 |
| 加入其他動作 | 從動作庫挑選，最近使用的排在最前面 |
| 第一組存檔時 | 自動建立當天的訓練（Session），不必先按「開始」 |
| 補記 | 可以把日期改成過去的某一天，用於補記 |

### SCR-02 記錄畫面

```
┌──────────────────────────────┐
│ ← 坐姿推胸機（Technogym）    ⓘ │
│ 上次（10/03）：40kg × 10, 10, 9 │
├──────────────────────────────┤
│ 重量  [ − ]   40   [ ＋ ] [kg▾]│
│ 次數  [ − ]   10   [ ＋ ]      │
│ 備註  ＿＿＿＿＿＿（可空白）      │
│                               │
│        [ ✓ 完成這組 ]          │
├──────────────────────────────┤
│ 1  40 kg × 10                 │
│ 2  40 kg × 9     （左滑刪除）   │
└──────────────────────────────┘
```

| 欄位 | 規則 |
|---|---|
| 重量 | 預設帶入：本次訓練的上一組；若本次還沒記，帶入該動作最近一次訓練的第 1 組 |
| 重量 ± 間距 | kg 預設 2.5、lb 預設 5、格數預設 1；每個動作可自訂 |
| 重量範圍 | 0–999.9，最多 1 位小數；徒手動作可空白（代表只用自身體重） |
| 單位 | 預設為動作項目的預設單位；點 [kg▾] 可改成 lb 或格數，只影響這一組以及之後的預帶值 |
| 次數 | 1–999 的整數，必填 |
| 備註 | 選填，最多 200 字 |
| 完成這組 | 存檔，組序自動加 1，並啟動休息計時器（SCR-03） |
| 修改／刪除 | 點已記錄的組可修改；左滑刪除，刪除前要確認 |
| ⓘ | 開啟 SCR-07，看完返回時回到這個畫面，輸入中的數值保留 |

### SCR-03 休息計時器（MRS-010）

| 項目 | 規則 |
|---|---|
| 啟動 | 「完成這組」後自動開始倒數 |
| 預設秒數 | 全域預設 90 秒；每個動作可自訂 |
| 操作 | −15 秒、＋15 秒、跳過 |
| 顯示 | 記錄畫面頂端的倒數條，不擋住輸入欄位 |
| 結束 | 響一聲提示音、震動、畫面閃爍 |
| 螢幕 | 訓練進行中保持螢幕常亮，避免自動鎖屏中斷計時 |
| 已知限制 | 手動鎖屏或切到其他 App 時不保證能提示；回到 App 後依實際經過時間顯示正確剩餘秒數。對策見 03_SW_Arch.md 第 6.3 節 |

### SCR-04 行事曆（MRS-009）

| 項目 | 規則 |
|---|---|
| 檢視 | 月曆。每天顯示排程的群組名稱，並以顏色標記狀態：已完成、未完成、未來 |
| 排程 | 點某一天，選一個訓練群組。一天最多排 1 個群組 |
| 重複 | 可設定「每週固定星期幾」，例如每週一、四做推日 |
| 修改 | 單日排程可改成別的群組或取消，不影響其他重複日 |
| 錯過的排程 | 只標示為「未完成」，不會自動順延 |
| 點已完成的日期 | 跳到該日的歷史紀錄（SCR-09） |

### SCR-05 訓練群組（MRS-008）

| 欄位 | 規則 |
|---|---|
| 群組名稱 | 必填，最多 20 字，不可重複 |
| 顏色 | 從 8 種顏色中選 1 種，用在行事曆上 |
| 訓練部位 | 多選，例如胸＋肩＋三頭 |
| 動作清單 | 從動作庫挑選，可拖曳排序；挑選時預設只列出符合所選部位的動作，也可切換為顯示全部 |
| 刪除 | 已被排程使用的群組刪除時，要確認是否一併取消未來的排程；過去的紀錄不受影響 |

### SCR-06 動作庫清單（MRS-001）

| 項目 | 規則 |
|---|---|
| 排序 | 預設依最近使用；可切換為依名稱 |
| 篩選 | 依訓練部位（多選）、依類型（機台／自由重量／徒手） |
| 搜尋 | 比對名稱與品牌，輸入時即時篩選 |
| 列表項目 | 縮圖、名稱、品牌、部位標籤 |
| ＋ | 新增項目（SCR-08） |

### SCR-07 動作項目頁（KPI-3：1 次點擊就看到說明和影片）

由上而下排列：

1. 照片
2. 名稱、品牌、類型、部位
3. **使用說明**（中文）
4. **注意事項**
5. 影片清單：每支影片顯示標題與起始時間，點一下就在頁內播放
6. 按鈕：「趨勢」（SCR-10）、「編輯」（SCR-08）

| 規則 | 說明 |
|---|---|
| 離線 | 第 1 到 4 項沒有網路也要能顯示（R-2）。影片在沒有網路時顯示「需要網路連線」，並保留「在 YouTube 開啟」的連結 |
| 播放 | 使用 YouTube 官方內嵌播放器，從設定的秒數開始播放 |

### SCR-08 動作項目編輯

| 欄位 | 必填 | 規則 |
|---|---|---|
| 名稱 | 是 | 最多 40 字；與既有項目同名時顯示警告，但仍可存檔 |
| 類型 | 是 | 機台／自由重量／徒手 |
| 品牌 | 否 | 最多 40 字 |
| 照片 | 否 | 拍照或從相簿選 1 張；存檔時自動縮小（長邊 1280 px） |
| 訓練部位 | 是 | 多選至少 1 項；可在此新增自訂部位（MRS-007） |
| 預設單位 | 是 | kg／lb／格數；徒手類型預設為「無」，可改 |
| 重量間距 | 否 | 依單位帶入預設值 |
| 休息秒數 | 否 | 留空時使用全域預設值 |
| 使用說明 | 否 | 多行文字，最多 2000 字 |
| 注意事項 | 否 | 多行文字，最多 1000 字 |
| 影片 | 否 | 可新增多支，每支欄位如下表 |

影片欄位：

| 欄位 | 規則 |
|---|---|
| YouTube 網址 | 接受 `youtube.com/watch?v=`、`youtu.be/`、`youtube.com/shorts/` 三種格式；無法辨識時顯示錯誤 |
| 起始時間 | 輸入格式為 `分:秒`；如果網址本身帶有 `t=` 參數，會自動帶入 |
| 標題 | 選填；留空時顯示「影片 1」、「影片 2」 |
| 排序 | 可上下移動 |

刪除規則：還沒有任何訓練紀錄的項目可以直接刪除。已有紀錄的項目只能「封存」，封存後不出現在清單與挑選畫面，但歷史紀錄與趨勢圖仍保留，避免資料遺失。

### SCR-09 歷史紀錄（MRS-004）

| 項目 | 規則 |
|---|---|
| 檢視 | 依日期由新到舊列出每次訓練，顯示群組名稱、動作數、總組數 |
| 展開 | 點一次訓練，展開每個動作的每一組 |
| 修改 | 可修改、刪除過去的組，刪除前要確認 |
| 篩選 | 依動作項目、依日期區間 |

### SCR-10 單一動作趨勢圖（MRS-004、KPI-5）

| 項目 | 規則 |
|---|---|
| 圖表 1：重量 | 橫軸為日期；縱軸為「當天該動作的最大重量」 |
| 圖表 2：訓練量 | 橫軸為日期；縱軸為「當天該動作的訓練量」 |
| 區間 | 1 個月／3 個月／6 個月／全部 |
| 單位處理 | 見第 6.1 節 |
| 資料不足 | 少於 2 天的紀錄時，顯示「紀錄累積 2 次以上才能畫趨勢」 |

### SCR-11 設定

| 項目 | 規則 |
|---|---|
| 預設重量單位 | kg／lb，新增動作時帶入 |
| 圖表顯示單位 | kg／lb |
| 預設休息秒數 | 30–600 秒，預設 90 秒 |
| 匯出 CSV | 見第 7.1 節 |
| 匯出 JSON（完整備份） | 見第 7.2 節 |
| 匯入 JSON | 見第 7.3 節 |
| 上次備份時間 | 顯示上次備份的時間；超過 14 天沒有備份時，在首頁顯示提醒（R-1） |

## 4. 主要操作流程

### FLOW-01 依排程記錄（KPI-2：10 秒內記錄一組）

1. 開啟 App，進入 SCR-01，畫面上已列出今天的排程動作。
2. 點一個動作，進入 SCR-02，重量與次數已帶入預設值。
3. 數值和預帶的一樣時，直接點「完成這組」，休息計時器開始倒數。
4. 數值不同時，按 ± 調整後再點「完成這組」。

點擊次數：數值相同時 2 次（步驟 2、3），只需調整重量時約 3 到 4 次。

### FLOW-02 自由訓練

在 SCR-01 點「自由訓練」，再點「＋ 加入其他動作」挑選動作，之後與 FLOW-01 的步驟 2 起相同。

### FLOW-03 建立新動作

依序為 SCR-06 →「＋」→ SCR-08，填完欄位後存檔，進入 SCR-07 確認內容。

### FLOW-04 排程

依序為 SCR-04 → 點日期 → 選群組 →（選擇性）設定每週重複 → 存檔。

### FLOW-05 換手機

1. 在舊手機的 SCR-11 匯出 JSON，透過雲端硬碟、Email 或 LINE 傳給自己。
2. 在新手機安裝 PWA，到 SCR-11 匯入該 JSON 檔。

## 6. 計算規則

### 6.1 單位

| 規則 | 說明 |
|---|---|
| 換算 | 1 lb = 0.45359237 kg（國際磅的定義值） |
| 儲存 | 每一組都保存「輸入時的數值與單位」，不做換算 |
| 趨勢圖 | kg 與 lb 的紀錄先換算成圖表顯示單位，畫在同一條線上。格數的紀錄畫成另一條線，使用右側縱軸。如果該動作只有格數紀錄，就只畫格數 |
| 同一天混用時 | 同一天同一動作同時有 kg／lb 與格數的紀錄時，兩條線各自計算，不互相換算 |

### 6.2 訓練量

| 情況 | 計算方式 |
|---|---|
| 有重量（kg／lb） | 每組的「重量 × 次數」加總，換算成圖表顯示單位 |
| 格數 | 每組的「格數 × 次數」加總，只用來和同一個動作比較，獨立成一條線 |
| 徒手（沒有填重量） | 總次數 |

## 7. 匯出與匯入

### 7.1 CSV（MRS-005）

- 每一組存成一列，編碼為 UTF-8 with BOM，讓 Excel 開啟時中文不會變成亂碼。
- 檔名格式為 `gymlog_sets_YYYYMMDD.csv`。

```
日期,群組,動作名稱,類型,組序,重量,單位,次數,備註
2026-10-07,推日,坐姿推胸機,機台,1,40,kg,10,
```

### 7.2 JSON 完整備份（MRS-005）

- 包含動作庫（含照片）、影片、部位、群組、排程、所有訓練紀錄與設定。
- 檔名格式為 `gymlog_backup_YYYYMMDD.json`。
- 檔案內記錄格式版本號，日後 App 改版時仍可以讀取舊版備份。
- 照片會讓檔案變大。估計 100 張照片約 10–30 MB（**估計值**，Arch 階段再確認）。

### 7.3 JSON 匯入（MRS-006）

| 規則 | 說明 |
|---|---|
| 模式 | **全部取代**：清空現有資料後換成備份檔內容（不做合併，以降低複雜度） |
| 確認 | 匯入前顯示備份檔的日期與筆數，並要求確認 |
| 自動保護 | 匯入前自動把目前資料匯出一份，萬一選錯檔案還能救回 |
| 驗證 | 格式錯誤或版本不相容時，拒絕匯入並說明原因，現有資料不動 |
